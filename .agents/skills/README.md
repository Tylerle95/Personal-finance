# Agent Skills Directory

Thư mục này chứa các tài liệu đặc tả kỹ năng (Skills) của Agent cho dự án **Personal Finance**.

## Định dạng kỹ năng (Skill Format)
Mỗi kỹ năng được định nghĩa dưới dạng một file Markdown (`.md`) chứa:
1. **YAML Frontmatter**: Mô tả tên kỹ năng, mục đích và khi nào cần kích hoạt.
2. **Hướng dẫn chi tiết (Detailed Instructions)**: Các bước thực hiện, code mẫu, công cụ dòng lệnh được khuyến nghị sử dụng.
3. **Quy tắc kiểm tra (Verification Checklist)**: Các điểm cần rà soát để đảm bảo chất lượng.

## Danh sách kỹ năng đề xuất (Ví dụ)
- `database-operations.md`: Kỹ năng xử lý truy vấn Supabase, tạo chính sách RLS.
- `pwa-setup.md`: Kỹ năng cấu hình Service Worker, manifest và kiểm tra hiển thị PWA.
- `responsive-styling.md`: Kỹ năng thiết kế Tailwind Mobile-First và kiểm tra breakpoint.
